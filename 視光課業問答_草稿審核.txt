【裂隙燈操作】（10題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1. 為什麼考試時用裂隙燈看的影像怎麼調都很模糊？
A：常見原因與解法：
1. 目鏡屈光補償未調整（最常見）→ 先遮一眼，轉動目鏡屈光補償環直到裂隙線條最清晰
2. 工作距離不對 → 搖桿前後移動，標準距離約 100 mm
3. 光軸未對齊 → 確認照明燈、目鏡、患者眼球三者同軸
4. 患者眼瞼未充分打開 → 請患者稍微睜大眼
5. 角膜水氣模糊（剛滴藥水）→ 稍待後再觀察
初學建議：先用低倍（8×）找到角膜反光點確認位置，再換高倍。

────────────────────────────────────

Q2. 為什麼有時候裂隙燈下看不清楚角膜結構？
A：原因與解法：
1. 目鏡屈光補償未調 → 遮單眼調整目鏡至裂隙清晰
2. 倍率選錯 → 看角膜層次需用 16–25×；整體掃描用 8–10×
3. 角膜水腫或淚膜破裂 → 請患者眨眼後再觀察
4. 患者配戴隱形眼鏡 → 部分鏡片材質散射光
技巧：先低倍調焦確認工作距離，再切換高倍精確觀察。

────────────────────────────────────

Q3. 裂隙燈光切法在現實中哪個時候會用到？
A：光切法（Optical Section）臨床應用：
1. 角膜層次評估：白斑、水腫位於上皮、基質或內皮哪一層
2. 晶狀體白內障位置：前囊、後囊或核性白內障
3. 前房深度估計（van Herick 法）
4. 人工水晶體（IOL）位置確認
5. 角膜異物深度判斷（是否需手術取出）
光切面越細（裂隙越窄），層次越清晰，但亮度較低。

────────────────────────────────────

Q4. 裂隙燈檢查中照明角度的改變會對觀察影像造成哪些影響？
A：主要照明技術與角度：
- 直接焦點照明：看角膜光學切面最清楚
- 廣角散射：小角度，整體眼前節觀察
- 後照法（Retroillumination）：穿透晶狀體反射，看角膜後沉積物（KP）
- 鏡面反射法（Specular reflection）：入射角＝反射角，看角膜內皮細胞
- 間接照明：旁側照明，看角膜水腫、血管
角度越大光切面越細越清楚；廣角低入射適合全面掃描。

────────────────────────────────────

Q5. 要怎麼用裂隙燈快速檢查完眼睛外觀？
A：系統化流程（STE-CA 順序）：
1. 眼瞼：低倍 8× 查眼瞼對稱、倒睫、眼瞼炎
2. 結膜：翻上眼瞼查 GPC，球結膜充血、乳頭或濾泡
3. 角膜：光切法各層透明度；螢光素染色查缺損
4. 前房：深度、Flare（房閃）、Cells（浮游體）
5. 晶狀體：核性、前後囊混濁
按此順序不遺漏，低倍定位後切換高倍細查。

────────────────────────────────────

Q6. 裂隙燈光切要怎麼準確看到細胞？
A：
角膜內皮細胞（Specular reflection 法）：
1. 裂隙燈 45–60° 角，高倍 40×
2. 找到「鏡面反射」區域（入射角＝反射角），呈蜂巢狀亮斑
3. 精確計數需配合內皮細胞鏡

前房浮游細胞（Cells & Flare）：
1. 細裂隙（1mm）、高倍（25–40×）、中等亮度
2. 聚焦前房中央，觀察浮動亮點
3. 細胞＋閃光（Flare）是葡萄膜炎的重要指標

────────────────────────────────────

Q7. 裂隙燈都看不到眼睛是怎麼回事？
A：找不到焦點的常見原因：
1. 患者臉未放穩 → 調整下巴托高度，使外眼角對準高度標記
2. 搖桿距離太遠 → 先推近至距眼約 10 cm
3. 光源未對準眼睛
4. 目鏡未歸零 → 先調目鏡屈光補償
5. 裂隙太細 → 先用 3mm 寬裂隙、低倍 8×
初學者：先看角膜反光點確認位置，再縮小裂隙。

────────────────────────────────────

Q8. 為什麼裂隙燈的倍率會影響看到的內容不同？
A：倍率與觀察目標對應：
- 低倍（6–10×）：整體眼前節掃描、眼瞼、結膜、角膜整體
- 中倍（16–20×）：角膜層次、前房細節、晶狀體
- 高倍（25–40×）：角膜內皮細胞、KP、前房浮游細胞
原則：先低倍找目標，再換高倍精確觀察。

────────────────────────────────────

Q9. 裂隙燈的黃光（鈷藍光）是用來檢查什麼的？
A：鈷藍光（Cobalt Blue Filter）的用途：
主要：螢光素染色（Fluorescein Staining）
- 激發螢光素發出黃綠色螢光
- 顯示角膜上皮缺損（染色陽性 = 綠色亮點）
- 觀察淚膜破裂時間（TBUT）
搭配黃色濾片：提高螢光素與背景對比
其他應用：RGP 隱眼螢光素配適圖型評估

────────────────────────────────────

Q10. 為什麼看光切片一定要從低倍（6×）開始看？
A：從低倍開始的原因：
1. 視野廣，容易找到角膜位置
2. 亮度足，先確認光切面位置再換高倍
3. 安全距離，高倍時鏡頭易太靠近患者
4. 先在低倍確認角度和位置，換高倍才不迷失
高倍（25–40×）用於細節觀察，但需先有低倍定位。

【屈光驗光】（17題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q11. 視網膜鏡怎麼快速判斷順動逆動方向？
A：
- 順動（With motion）：反光與鏡面移動方向相同 → 受測眼為遠視 → 加正鏡
- 逆動（Against motion）：反光移動方向相反 → 受測眼為近視 → 加負鏡
- 中和（Neutralization）：光充滿瞳孔，無明確移動方向 → 此度數即工作距離度數
口訣：「順加正，逆加負，無動中和」
工作距離補償：1m → 減 -1.00D；67cm → 減 -1.50D

────────────────────────────────────

Q12. 如果視網膜鏡分不清楚哪個軸度比較亮怎麼辦？
A：解決方法：
1. 增加工作距離（拉遠至 75–100 cm）讓反射更清晰
2. 暗室條件讓反射更明顯
3. 換細光帶（Streak retinoscope）比斑點光更容易分辨方向
4. 試加 +0.50D 柱鏡觀察哪個方向光帶變清楚，藉此確認軸度
5. 仍無法確認時，以電腦驗光結果作起點，再用 JCC 修正

────────────────────────────────────

Q13. 檢影鏡的光學十字為什麼兩個度數是一樣的？
A：若兩個主子午線度數相同，代表：
純球面屈光狀態（無散光）→ 所有方向反射光動向一致
確認方法：旋轉檢影鏡 360°，反射光帶移動方向與速度保持不變
若有散光：兩主子午線的中和距離不同，反射光動向也不同。

────────────────────────────────────

Q14. 檢影鏡如何精準找到散光軸度？
A：步驟：
1. 先中和球面（加球鏡讓至少一個方向達中和）
2. 旋轉檢影鏡，找「反射光帶最細、最亮、移動最一致」的方向 → 此為主子午線
3. 在此軸上中和一個方向，再中和另一方向
4. 使用 JCC 精確校正軸度與度數
關鍵：光帶斜向移動代表軸度未對準 → 旋轉套管使光帶與移動方向一致

────────────────────────────────────

Q15. 檢影鏡怎麼區分球面度數和散光？
A：
球面：旋轉任何角度，反射光帶移動方向和速度相同
散光：不同方向反射光動向不一致（有快有慢）；未對準軸度時光帶出現斜向移動
步驟：
1. 先找順/逆動確認球面成分，加球鏡
2. 旋轉找最清晰方向，加柱鏡中和
3. 轉 90° 中和另一方向 → 完整球柱組合

────────────────────────────────────

Q16. 如何快速幫患者驗光？
A：快速驗光流程（5步驟）：
1. 電腦驗光取得客觀起始值
2. 霧視（Fogging）清除調節干擾，加正鏡至視力降至 0.1–0.2
3. 球面調整（MPMVA）：找最大正度數最佳視力
4. JCC 散光修正：先確認軸度再確認度數
5. 雙眼平衡
技巧：信任電腦驗光散光軸作起點，省去軸度搜尋時間。

────────────────────────────────────

Q17. 翻轉鏡（JCC）要怎麼使用比較不會手跑掉？
A：穩定使用技巧：
握法：拇指和中指夾住圓柄兩側小凸點，翻轉時只旋轉手腕（不移動整手）
翻轉動作：兩位置交替，每次約 0.5 秒，問患者「1號清楚還是2號清楚？」
穩定技巧：手肘靠在台座；先讓患者定好注視目標再放 JCC
順序：先確認軸度 → 再確認度數

────────────────────────────────────

Q18. 驗光時受測者配合度不佳會對視力量測造成哪些影響？
A：影響：
1. 過度調節 → 結果偏近視（過矯）
2. 瞇眼效應 → 視力暫時提高，誤導終點
3. 眨眼過頻 → 淚膜不穩定，視力波動
4. 注視偏移 → 結果不可靠
解法：衛教「請放鬆看，模糊也沒關係」；霧視法抑制調節；兒童用遊戲化指示。

────────────────────────────────────

Q19. 頂點距離減少時，所需矯正度數會更正還是更負？
A：鏡片離眼越近（VD 減少）：
- 正鏡（遠視）：有效度數增加 → 需減少正度數
- 負鏡（近視）：有效度數減少 → 需增加負度數
例：-10.00D 框架鏡（VD=12mm）改隱眼 → 約 -8.93D
實務：度數 ≥ ±4.00D 時必須換算。

────────────────────────────────────

Q20. 框架眼鏡與隱形眼鏡在驗配時，頂點距離對度數影響有多大？
A：度數 <±4.00D：影響小，通常不需換算
度數 ≥±4.00D：需計算換算（±8.00D 以上誤差可達 1D 以上）
換算公式：CL = F / (1 - 0.012 × F)

────────────────────────────────────

Q21. 為什麼測量環境亮度會影響驗光結果？
A：明亮環境（瞳孔縮小）：針孔效果使小度數誤差被掩蓋；調節增加偏近視
暗環境（瞳孔散大）：調節放鬆，更接近真實度數（對遠視特別重要）
標準：半暗室條件；散瞳驗光完全排除調節干擾。

────────────────────────────────────

Q22. 什麼情況下針孔無法改善視力？
A：以下情況針孔無效：
1. 視網膜病變（黃斑部病變、視網膜脫離）
2. 視神經病變（青光眼、視神經炎）
3. 皮質性視覺缺損（腦部病變）
4. 嚴重角膜混濁
5. 嚴重白內障
6. 弱視（神經發育問題）
臨床意義：針孔無法改善 → 需進一步眼科評估。

────────────────────────────────────

Q23. 視力值和屈光度數是一樣的東西嗎？
A：不一樣。
視力值（VA）：功能性指標，測量分辨細節的能力（視力1.0=能辨識1分弧度視標）
屈光度數（D）：光學測量值，表示眼睛聚焦能力（如近視 -3.00D）
相同度數的近視，矯正後視力可能不同，因為視力還受視網膜、視神經、大腦等影響。

────────────────────────────────────

Q24. 為什麼初配眼鏡不宜度數一次開足？
A：原因：
1. 睫狀肌已習慣補償狀態，全矯正時突然變化 → 頭暈、噁心
2. 大腦需 2–4 週適應新清晰度
實務原則：近視通常全矯；遠視初配給 50–75% 逐漸增加；老花從最低加入度開始
兒童遠視矯正不足易造成弱視。

────────────────────────────────────

Q25. 為什麼近視的人看遠處模糊，看近處卻相對清楚？
A：近視眼軸過長，平行光聚焦在視網膜前 → 遠處模糊
看近時光線發散，焦點後移 → 恰好落在視網膜 → 相對清晰
換算：-3.00D 近視不配鏡的清楚距離 ≈ 33cm

────────────────────────────────────

Q26. 散光軸度是如何判斷的？如果軸度錯誤會有什麼影響？
A：判斷方法：電腦驗光（起點）、JCC 主觀驗光（確認）、角膜地形圖
軸度錯誤影響：
- ±5°：輕微扭曲，多數患者可接受
- ±10°：明顯扭曲，閱讀困難
- ±15° 以上：嚴重不適、頭痛
- 斜軸散光（30–60° 或 120–150°）的軸度錯誤比順逆規更明顯

────────────────────────────────────

Q27. 為什麼高度數遠視的患者數量少於高度數近視？
A：原因：
1. 輕中度遠視可透過調節自行補償，不影響日常，不就診
2. 輕度遠視直到老花才被發現
3. 近視有強烈的環境因素（近距離用眼過多）；高度遠視多為先天眼軸短
4. 兒童期多數會逐漸正視化，少數才保持高度遠視

【隱形眼鏡】（18題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q28. 長期戴隱眼，什麼情況下應該停戴？
A：立即停戴的情況：
1. 眼睛紅痛、畏光、大量分泌物（疑似角膜感染）
2. 視力突然下降
3. 螢光素染色陽性（角膜上皮缺損）
4. 配戴時明顯異物感無法改善
5. 急性結膜炎或眼部感染期間
6. 游泳、洗澡前後
停戴後症狀超過 24 小時未改善，需就醫。

────────────────────────────────────

Q29. 為什麼硬式隱形眼鏡矯正散光效果比較好，但配戴率較低？
A：矯正散光優於軟式的原因：
鏡片硬度高，配戴後形成「淚鏡」，可中和角膜散光（尤其不規則散光效果顯著）
配戴率低的原因：初期異物感強（適應期 1–4 週）、護理複雜、激烈運動易脫落、價格較高

────────────────────────────────────

Q30. 為什麼隱形眼鏡的邊緣設計會決定配戴舒適度？
A：
- 厚邊 → 上眼瞼壓力增加 → 異物感↑
- 薄邊/圓弧邊 → 減少摩擦，舒適度↑
- 邊緣翻翹 → 鏡片移動過大、乾燥加速
- 好的邊緣設計讓淚液均勻分布，延長舒適時間
不同品牌邊緣幾何不同，建議試戴評估。

────────────────────────────────────

Q31. 高含水量與低含水量隱形眼鏡有什麼差別？各適合哪些族群？
A：
高含水量（>54%）：初期舒適，易從眼表吸收淚液導致後期乾澀 → 適合淚液正常者
低含水量（<54%）：全天舒適度穩定，耐蛋白質沉積 → 適合乾眼症患者
現代矽水膠（Silicone Hydrogel）：透氧性高，是目前主流。

────────────────────────────────────

Q32. 臨床上如何評估配戴隱形眼鏡時的角膜缺氧風險？
A：評估指標：
1. Dk/t 值：日戴需 >24；夜戴需 >87
2. 配戴時數：每日 >12 小時風險高
3. 裂隙燈徵象：角膜新生血管（>1.5mm）、上皮微囊水腫
4. 問卷：是否睡覺/游泳戴隱眼

────────────────────────────────────

Q33. 如果隱形眼鏡在眼睛裡碎掉該怎麼處理？
A：
1. 立刻停止揉眼
2. 大量生理食鹽水沖洗，向鼻側方向沖
3. 翻轉眼瞼找碎片，濕棉棒輕輕取出
4. 無法取出或有疼痛、視力下降 → 立即就醫
軟式碎裂：生理食鹽水潤濕後較易取出；硬式碎裂邊緣銳利務必就醫。

────────────────────────────────────

Q34. 隱形眼鏡清潔消毒沒消毒好可能會造成哪些風險？
A：風險由輕到重：
1. 蛋白質沉積 → 舒適度下降、GPC（巨乳頭結膜炎）
2. 細菌生物膜 → 反覆感染
3. 棘阿米巴角膜炎（Acanthamoeba）：用自來水最危險，治療困難可能失明
4. 細菌性角膜潰瘍（Pseudomonas 最常見）：48–72 小時可穿孔
正確清潔：揉搓 20 秒 → 保存液浸泡 6 小時 → 鏡盒每 3 個月換新

────────────────────────────────────

Q35. 要怎麼幫別人更順利地戴上隱形眼鏡？
A：
1. 確認鏡片正反面（邊緣垂直＝正面；外翻＝反面）
2. 請對方眼睛向前看，勿刻意眨眼
3. 輔助者輕撐上下眼瞼（撐開睫毛根部）
4. 鏡片輕放於角膜上，輕拍對準
5. 輕閉眼一次再眨眼對焦
常見失敗：患者緊張 → 說「眼睛向下看」轉移注意力。

────────────────────────────────────

Q36. 為什麼有些人隱眼戴上去會有刺痛感？
A：常見原因：
1. 鏡片正反面戴反（最常見）
2. 鏡片表面有異物或損傷
3. 乾眼或淚膜不穩定 → 戴前先滴人工淚液
4. 過敏反應（對保存液防腐劑過敏）
5. 角膜上皮已有微小缺損 → 停戴就醫
戴上後 5 分鐘內刺痛未消，立即取下。

────────────────────────────────────

Q37. 硬式隱形眼鏡的清潔方式有哪些？
A：RGP 清潔步驟：
1. 揉搓：RGP 專用清潔液，兩面各揉搓 20 秒，生理食鹽水沖洗
2. 消毒保存：浸泡 RGP 專用保存液至少 4–6 小時（勿用軟式保存液代替）
3. 除蛋白：每週一次酵素錠或 RGP 除蛋白液
禁忌：勿用自來水沖洗（棘阿米巴風險）

────────────────────────────────────

Q38. 基弧和正交弧的差異是什麼？要怎麼判斷？
A：
基弧（BOZR）：鏡片後表面中央弧度，直接接觸角膜
正交弧（Peripheral Curves）：外圍弧度，比基弧平坦，確保淚液交換
配適判斷（螢光素圖型）：
- On K：螢光均勻 → 理想
- Steep（陡）：中央積液深染
- Flat（平）：中央接觸，螢光少

────────────────────────────────────

Q39. 何時應建議配戴 RGP 而非軟式隱眼？
A：建議選擇 RGP：
1. 不規則角膜散光（圓錐角膜、角膜疤痕）
2. 高度角膜散光（>2.50D）
3. 乾眼症（淚液交換較佳）
4. 軟式試戴多次仍視力不佳
5. 視覺品質要求高的患者

────────────────────────────────────

Q40. 為什麼角膜塑型片（OK鏡）晚上戴完隔天視力會變好？
A：原理：
反幾何設計夜戴時壓平角膜中央，等效減少近視度數
效果持續約 12–16 小時；需配戴 6–8 小時效果最佳
重要：效果是可逆的，停戴 1–2 週後角膜恢復，近視度數回來。

────────────────────────────────────

Q41. 為什麼有些人的硬式隱眼戴上沒多久就有白色沉澱物？
A：白色沉澱物來源：
1. 鈣質沉積（淚液中鈣離子與鏡片結合）
2. 蛋白質沉積（免疫球蛋白、白蛋白）
3. 黏液沉積（乾眼症患者更嚴重）
解決：增加清潔頻率、每週酵素除蛋白、更換鏡片材質。

────────────────────────────────────

Q42. 為什麼有人說不小心戴硬式隱眼睡覺也沒什麼問題？
A：這個說法不正確，有以下風險：
1. 角膜缺氧
2. 睡姿造成角膜壓力不均
3. 醒來時鏡片黏貼角膜，強行取下可能刮傷
4. 睡眠時淚液減少，感染風險增加
偶爾一次影響較小，但不能養成習慣。OK鏡才是設計用來夜戴的。

────────────────────────────────────

Q43. 若用食鹽水清理硬式隱眼後直接戴上眼睛會有什麼影響？
A：問題：
1. 未消毒：細菌未被殺滅，感染風險
2. 生理食鹽水無潤濕成分 → 初期乾澀感
3. 未調節 pH 值，可能刺激眼表
正確流程：清潔 → 生理食鹽水沖洗 → 浸泡保存液 4 小時 → 戴前再沖洗

────────────────────────────────────

Q44. 視力測量標準一定要 6 公尺嗎？
A：6 公尺是國際標準（接近平行光，等同無限遠），但非唯一方式：
- 4 公尺：使用 4m 修正視力表
- 3 公尺（ETDRS）：研究和低視力常用，需換算
- 鏡面反射：3m 鏡前等效 6m
距離可調整，但必須換算為等效 6m 標準。

────────────────────────────────────

Q45. 軟式隱形眼鏡要怎麼衛教（清洗、配戴）？
A：配戴前：洗手擦乾 → 揉搓鏡片 20 秒 → 沖洗 → 放食指尖 → 拉開眼瞼 → 放上角膜 → 眨眼對焦
取下後：揉搓 → 保存液浸泡 6 小時以上
鏡盒：每日換新藥水；每 3 個月換新鏡盒
禁忌：游泳/洗澡配戴、睡覺配戴、自來水清洗

Q46. 為什麼在磨鏡片時吸盤會滑動導致鏡片壞掉？
A：原因與預防：
1. 鏡片表面有油脂或水分（最常見）→ 酒精棉片徹底清潔
2. 吸盤老化 → 更換吸盤
3. 施力不均 → 保持穩定手勢
4. 特殊鍍膜表面滑 → 使用防滑貼片
5. 高曲率鏡片難定位 → 先用中心定位儀確認

────────────────────────────────────

Q47. 要怎麼快速磨出鏡片而且不會磨錯？
A：快速且正確磨片 5 步驟：
1. 核對處方（球面、散光、軸度）
2. 中心定位機標記 OC 位置
3. 清潔鏡片後吸盤垂直固定，確認氣密
4. 磨片機選正確模板，輸入 PD/高度
5. 磨後驗度儀核對度數、光心位置

────────────────────────────────────

Q48. 光學中心和幾何中心是同一個東西嗎？
A：不一樣。
光學中心（OC）：屈光力實際通過點，光線通過時無稜鏡效應
幾何中心（GC）：鏡片外框形狀的幾何中心
若 OC 偏離瞳孔 → 產生稜鏡效應 → 頭痛、複視
實務：驗度儀打點確認 OC，再對準瞳孔位置加工。

────────────────────────────────────

Q49. 如何快速且正確測量主要參考點（MRP）的高度？
A：步驟：
1. 患者配戴試鏡架坐正前視
2. 操作者與患者視線等高
3. 在瞳孔前方打點
4. 測量瞳孔中心到鏡框下緣的垂直距離 = 配鏡高度
數位瞳孔定位儀：拍照自動計算，精確（誤差 <0.5mm）。

────────────────────────────────────

Q50. 用驗度儀量有散光的鏡片，要如何分長軸和短軸、哪個是 180° 哪個是 90°？
A：步驟：
1. 放上鏡片，中心對準
2. 調節目鏡，會看到兩組線條
3. 先對焦一組線條記錄度數 D1，再對焦另一組記錄 D2
4. 差值 = 散光度數；線條對齊的刻度 = 散光軸度
記憶：線條「方向」= 散光軸度

────────────────────────────────────

Q51. 鏡片是怎麼有度數的？
A：鏡片度數來自表面曲率（彎曲的材料改變光路）：
正鏡（凸鏡）：中央厚邊緣薄，光線匯聚 → 矯正遠視
負鏡（凹鏡）：中央薄邊緣厚，光線發散 → 矯正近視
折射率越高 → 相同度數所需曲率越小 → 鏡片越薄

────────────────────────────────────

Q52. 鏡片不同材質的差別是什麼？
A：主要材質比較：
CR-39 折射率1.50：光學品質好，較厚，適合低度數
Polycarbonate 1.59：抗衝擊，適合兒童/運動（阿貝值較低）
High-index 1.67：薄，適合高度數
High-index 1.74：最薄，適合極高度數（周邊色差較明顯）
Trivex 1.53：抗衝擊+阿貝值最高，色差最少
阿貝值越高 = 色散越少 = 視覺品質越好

────────────────────────────────────

Q53. 為什麼有些人就算戴漸進多焦點眼鏡看近還是習慣脫眼鏡？
A：原因：
1. 近用區太窄，需要側轉頭才能找到清晰區
2. 加入度太高，「低頭看近」感覺不自然
3. 舊習慣難改（長期戴單焦點者）
解決：確認配鏡高度正確；適應期 2–4 週積極多用；考慮電腦用鏡作為過渡。

【鏡框調整與光學】（5題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q54. 鏡框的選擇怎麼影響光學中心和視覺舒適度？
A：選框影響：
1. 框架 PD 接近瞳距 → OC 偏心越小，稜鏡效應越小
2. 過大框 → OC 偏離瞳孔 → 頭痛、視疲勞
3. 高度數選小框：減少邊緣厚度與稜鏡效應

────────────────────────────────────

Q55. 鏡框大小、鼻墊高度與鏡腳調整，如何影響配戴舒適度與視覺品質？
A：
鏡框大小：OC 偏離越大，稜鏡效應越大；大框重量增加
鼻墊高度：太低→睫毛觸碰鏡片；太高→頂點距離增加；正確→鏡框上緣在眉毛位置
鏡腳：角度不對→耳後壓痛；過短/過長→眼鏡滑動，PD 偏移

────────────────────────────────────

Q56. 為什麼同一患者戴不同鏡框視覺清晰度會不同？
A：原因：
1. OC 偏移不同 → 稜鏡效應不同
2. 頂點距離差異 → 有效度數改變（高度數影響明顯）
3. 傾斜角不同 → 鏡片有效球柱度改變
4. 鏡片材質/廠牌像差不同
高度數換框必須重新確認 VD 和傾斜角。

────────────────────────────────────

Q57. 眼鏡配戴不當可能產生哪些問題？
A：光學問題：OC 偏離→稜鏡效應→頭痛雙影；VD 不對→有效度數不符
物理不適：鼻墊壓力不均→鼻樑壓痛；耳掛過緊→耳後痛；鏡架歪斜→雙眼高度不一
長期：高度數未正確驗配→弱視（兒童）；持續稜鏡效應→眼肌疲勞惡化

────────────────────────────────────

Q58. 如何向患者解釋散光？
A：比喻：
「正常眼睛的角膜像籃球，各方向曲率一樣；
散光的角膜像橄欖球，一個方向比較彎，另一個比較平，
光線無法在同一個點聚焦，看東西邊緣模糊或有拉長扭曲感。」
患者感受：看燈光有拖影；斜線比水平線難看清；長時間閱讀特別疲勞
矯正：柱面鏡或環曲面隱眼，需指定軸度方向。

【眼睛疾病】（9題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q59. 青光眼在什麼年齡階段會發生？
A：依類型不同：
- 先天性青光眼：出生至 3 歲
- 原發性開角型（POAG）：40 歲後風險增加，60 歲以上盛行率顯著上升
- 急性閉角型：50 歲以上，東亞女性多見
風險因子：高眼壓、家族史、高度近視（>-6D）、糖尿病

────────────────────────────────────

Q60. 前房隅角分級如何判斷？
A：Shaffer 分級系統（0–4 級）：
- 4級（35–45°）：可見全部隅角結構
- 3級（25–35°）：可見鞏膜突
- 2級（20°）：可見前小梁，有閉角風險
- 1級（≤10°）：高閉角風險
- 0級（閉角）：看不見任何結構
以房角鏡（Gonioscopy）觀察；1–2 級需考慮預防性雷射（LPI）。

────────────────────────────────────

Q61. 白內障手術的成功率和術後注意事項是什麼？
A：成功率：視力改善率超過 95%，術後 3 個月視力穩定。
術後前 2 週：
禁止：游泳、泡湯、揉眼、提重物、趴睡
術後 1 個月：避免粉塵環境、強烈震動
按時點眼藥水（抗生素＋消炎）是術後護理核心。

────────────────────────────────────

Q62. 白內障對人會有什麼影響？
A：早期：視力模糊、霧化感；近視度數增加；色覺偏黃
中期：眩光嚴重，夜間駕車困難；對比敏感度下降；單眼複視
晚期：視力降至光感（LP）；可能繼發青光眼
治療：手術（人工水晶體置換）是唯一根本治療方式。

────────────────────────────────────

Q63. 後發性白內障和後囊性白內障怎麼分辨？
A：
後囊性白內障（PSC）：白內障的一種，位在晶狀體後囊下；強光/近距離時症狀更明顯
後發性白內障（PCO）：白內障手術後的後遺症，殘留上皮細胞增生
治療：YAG 雷射後囊切開（門診 5 分鐘）
簡記：「PSC 手術前，PCO 手術後」

────────────────────────────────────

Q64. 虹膜嚴重損傷會有哪些症狀？
A：輕度：瞳孔散大、對光反應遲鈍、畏光、短暫視力下降
中重度：瞳孔形狀異常（梨形/D形）、多瞳孔、嚴重畏光眩光
嚴重：持續畏光需配戴人工虹膜隱眼；可能繼發青光眼；白內障風險增加

────────────────────────────────────

Q65. 為什麼長時間近距離用眼容易加深近視？
A：機制：
1. 調節滯後 → 視網膜後方遠視性離焦訊號 → 刺激眼軸延伸
2. 周邊視網膜遠視性離焦 → 持續刺激眼軸增長
預防：20-20-20 法則；每天戶外活動 ≥ 2 小時；OK鏡/低濃度阿托品

────────────────────────────────────

Q66. 人眼睛失明時是眼前全黑還是什麼感覺？
A：因失明原因不同：
- 視網膜/視神經完全損傷：通常是「那個方向不存在感」，非全黑
- 皮質性盲：可能有光感但無法形成影像
- 光感殘留（LP）：僅能分辨亮暗
- 先天盲：從未有視覺記憶者，無法想像「黑色」，夢中也無視覺影像
「黑色」本身也是一種視覺感受，完全失去視覺不等於「全黑」。

────────────────────────────────────

Q67. 為何角膜塑型片（OK鏡）需要嚴格追蹤回診？
A：回診原因：
1. 安全監控：定期螢光素染色確認無角膜損傷
2. 效果評估：角膜地形圖比較；眼軸測量（每 6 個月）
3. 處方調整：角膜形態改變後可能需更換弧度
回診時間：配戴後 1 天 → 1 週 → 1 個月 → 每 3 個月
緊急狀況：眼紅痛 → 立即停戴就醫

【儀器操作】（4題）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q68. 儀器沒有校正好直接使用會有哪些問題？
A：各儀器未校正的影響：
眼壓計：讀數偏高/偏低，誤診青光眼或漏診
角膜曲率計：K 值不準，影響隱眼基弧選擇和 OK鏡設計
綜合驗光儀：散光軸不準
視力表投影機：視力低估或高估
解決：定期校正（至少每半年）；建立校正記錄。

────────────────────────────────────

Q69. 為什麼有些人的上眼瞼比較難翻起來？
A：原因：提瞼肌張力過強；患者緊張；睫毛較長阻礙
技巧：
1. 請患者眼睛向下看（放鬆提瞼肌）
2. 拇指靠近睫毛根部，食指橫放瞼板上緣（距睫毛約 8–10mm）
3. 右手向下向前，左手向後壓 → 自然翻轉
4. 動作要快而果斷
難翻時：表面麻醉藥可減少反射。

────────────────────────────────────

Q70. 稜鏡的方向要如何判斷和記憶？
A：基本原理：稜鏡偏折光線朝底部（Base）→ 像往尖端方向移動
口訣：「光往底走，像往尖走」
臨床：底 IN（BI）矯正外隱斜；底 OUT（BO）矯正內隱斜；底 UP/DOWN 矯正垂直隱斜
Prentice's Law：Δ = D × d（d=偏心距離cm，D=鏡片度數）

Q71. 市面上讓眼睛涼涼的眼藥水真的有用嗎？原理是什麼？
A：「清涼感」來自薄荷醇刺激冷覺接受器（TRPM8 通道），是感官刺激，非治療效果。
有效成分才重要：
- 潤滑：玻尿酸（HA）→ 確實有效
- 收縮血管：鹽酸四氫唑啉 → 眼白暫時變白，長期使用可能反彈充血
結論：清涼感 ≠ 治療。真正的眼疲勞需要休息；乾眼需使用無防腐劑人工淚液。

Q72. 眼鏡鏡片如何正確清洗？
A：步驟：
1. 先用清水沖掉灰塵（避免乾擦刮傷鍍膜）
2. 擠少量中性清潔劑（稀釋洗碗精），指腹輕柔揉洗
3. 清水徹底沖洗乾淨
4. 超細纖維眼鏡布輕輕拭乾
禁忌：熱水（>60°C 損傷鍍膜）、酒精擦拭、乾擦（砂粒刮花）

────────────────────────────────────

Q73. 為什麼鏡框眼鏡戴一整天鏡片上會有髒污？
A：髒污來源：
1. 皮脂：臉部/睫毛皮脂腺分泌，隨眨眼和皮膚接觸附著（最主要）
2. 指紋：觸碰鏡片時留下油脂
3. 化妝品：粉底、睫毛膏顆粒飄落
4. 空氣中灰塵和油煙
疏水疏油鍍膜可減少油污附著，讓清洗更容易。

────────────────────────────────────

Q74. 為什麼眼鏡鼻墊會變綠色？
A：銅綠（碳酸銅）形成：
金屬鼻墊支架（銅合金）長期接觸汗液（水分、鹽分、酸性物質），氧化反應產生銅綠，積在矽膠鼻墊紋路中。
預防：每 1–2 個月超音波清洗；每日清洗鼻墊；選擇鈦金屬或不鏽鋼支架。

────────────────────────────────────

Q75. 沐浴乳或洗髮精不小心進入眼睛要怎麼處理？
A：緊急處理：
1. 立刻停止揉眼
2. 大量生理食鹽水（或乾淨清水）持續沖洗至少 15–20 分鐘，向鼻側方向沖
3. 翻開眼瞼確認有無殘留
4. 仍有刺痛、視力模糊、持續發紅 → 就醫
注意：強鹼（如漂白水）傷害嚴重，需緊急就醫。

────────────────────────────────────

Q76. 眼鏡鏡片多久要清洗一次？
A：建議頻率：
- 最理想：每天清洗（使用後）
- 最少：每 2–3 天一次
特殊情況需立即清洗：接觸油煙/化妝品後、運動後（汗水易損傷鍍膜）
記憶：「每天洗眼鏡，跟刷牙一樣重要」
不建議用衣服、紙巾乾擦，即使只是「稍微擦一下」也會累積刮傷。

────────────────────────────────────

Q77. 配鏡時瞳孔距離要怎麼測量？
A：測量方法：
單眼 PD（最精確）：遮住測量者右眼，尺靠鼻樑，記錄患者右瞳孔中心到鼻樑中線距離（RPD）；再遮左眼測 LPD
雙眼 PD：右眼瞳孔中心到左眼瞳孔中心距離
注意：近距離配鏡 PD 應減少 2–4mm（雙眼內聚）
誤差影響：1mm PD 誤差在 3.00D 鏡片 → 產生 0.3Δ 稜鏡
